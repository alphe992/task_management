Task Management System



A MySQL database script for a simple Task Management Application. It establishes relational 
tables for managing users and their assigned tasks, along with initial seed data.


Features
User Management: Track user accounts with auto-incrementing primary keys.

Task Tracking: Assign tasks to users with status tracking (To Do, In Progress, etc.) and due dates.

Relational Integrity: Enforces foreign key constraints between tasks and users.


Setup Instructions
1. Open your MySQL client or database administration tool (e.g., MySQL Workbench, phpMyAdmin).

2. Run the SQL script to create the Task Management database and populate the initial tables.
